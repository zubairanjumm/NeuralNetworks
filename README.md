# Neural Networks

A collection of neural network implementations built from scratch to understand how neural networks work internally.

## What this repository contains

* Neural networks implemented from scratch
* Forward propagation
* Loss calculation
* Backpropagation
* Gradient calculation
* Weight updates
* Training loops
* Different architectures and experiments

The goal is to focus on understanding the underlying mathematics and mechanics rather than relying entirely on high-level deep learning frameworks.

## Structure

Each neural network is kept as a separate implementation or experiment, making it easier to compare different approaches and progressively build more complex networks.

## Tech Stack

* Python
* NumPy
* Mathematics & Linear Algebra

## Goal

Build neural networks from the ground up and develop a strong understanding of how modern deep learning systems work under the hood.
